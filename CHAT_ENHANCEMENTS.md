# Улучшения AI Чата - Markdown и Изменяемый Размер

## Реализованные функции

### 1. Поддержка Markdown форматирования

Теперь сообщения от AI отображаются с полной поддержкой Markdown:

#### Поддерживаемые элементы:
- **Заголовки** (H1-H6)
- **Жирный** и *курсив*
- Списки (маркированные и нумерованные)
- Блоки кода с подсветкой синтаксиса
- Инлайн код
- Цитаты (blockquote)
- Таблицы (GitHub Flavored Markdown)
- Ссылки

#### Подсветка синтаксиса кода:
- JavaScript/TypeScript
- Python
- JSON
- JSX/TSX
- И другие популярные языки

### 2. Изменяемый размер чата (ChatWidget)

ChatWidget теперь поддерживает два режима отображения:

#### Режимы:
- **Обычный**: 380px × 500px
- **Увеличенный**: 600px × 700px

#### Управление:
- Кнопка развертывания/свертывания в заголовке чата
- Плавная анимация перехода между размерами
- Адаптивность под размер экрана

### 3. Улучшенный ChatModal

Dialog теперь использует:
- Размер `lg` (большой) для лучшей читаемости
- Высота 80% viewport (максимум 800px)
- Полностью адаптивный layout

## Компоненты

### MarkdownMessage

Новый компонент для рендеринга сообщений с Markdown.

**Расположение**: `src/components/MarkdownMessage.tsx`

**Props**:
```typescript
interface MarkdownMessageProps {
  content: string;
  role: 'user' | 'assistant';
}
```

**Особенности**:
- Различный стиль для пользователя и AI
- Адаптивная ширина (до 85% контейнера)
- Стилизованные блоки кода с темой VS Code Dark
- Правильное форматирование таблиц и списков

### ChatModal (обновлен)

**Изменения**:
- Импортирует `MarkdownMessage` вместо простого `Paper`
- Убран `Paper` из импортов
- Использует `maxWidth="lg"` для большего размера
- Высота диалога: 80vh (максимум 800px)

### ChatWidget (обновлен)

**Новые возможности**:
- State `isExpanded` для отслеживания режима
- Кнопка развертывания с иконками:
  - `OpenInFullIcon` - для увеличения
  - `CloseFullscreenIcon` - для уменьшения
- Плавный переход размеров (transition: all 0.3s)
- Использует `MarkdownMessage` для отображения


- Плавная прокрутка к новым сообщениям

## Технические детали

### Регистрация языков для подсветки

```typescript
import { Light as SyntaxHighlighter } from 'react-syntax-highlighter';
import javascript from 'react-syntax-highlighter/dist/esm/languages/prism/javascript';

SyntaxHighlighter.registerLanguage('javascript', javascript);
```

Использование `Light` версии вместо `Prism` для:
- Меньшего размера бандла
- Ручной регистрации только нужных языков
- Лучшей производительности

### Обработка конфликта типов React

Используется `React.createElement()` для обхода конфликта типов между версиями React:

```typescript
return React.createElement(SyntaxHighlighter as any, {
  style: vscDarkPlus,
  language: language,
  children: code
});
```
