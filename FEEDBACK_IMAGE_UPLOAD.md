## Image Upload Flow

```
1. User fills form fields
   ↓
2. User clicks "Прикрепить скриншот"
   ↓
3. File picker opens
   ↓
4. User selects image file
   ↓
5. System validates:
   - File type (must be image)
   - File size (max 5MB)
   ↓
6. If valid:
   - Image converted to base64
   - Preview shown in modal
   - X button available to remove
   ↓
7. User can continue editing or submit
   ↓
8. On submit:
   - Image included in API request
   - Embedded in GitHub issue
```

## Features

✅ **Optional Upload**
- Users can submit feedback without images
- Button text clearly indicates it's optional

✅ **File Validation**
- Accepts: PNG, JPEG, JPG, GIF, WebP
- Maximum size: 5MB
- Clear error messages

✅ **Preview & Remove**
- Thumbnail preview before submission
- X button to remove image
- Can change mind before submitting

✅ **GitHub Integration**
- Images embedded in markdown
- Displayed under "Screenshot" section
- Base64 encoding for reliability

✅ **User Feedback**
- Loading states during upload
- Success/error alerts
- Clear visual feedback

## Code Architecture

```
FeedbackModal.tsx
├─ useState for image state
├─ useRef for file input
├─ handleImageSelect()
│  ├─ Validate file type
│  ├─ Validate file size
│  ├─ Read as base64
│  └─ Set preview
├─ handleRemoveImage()
└─ handleSubmit()
   └─ Include image in request

API Route
├─ Parse request body
├─ Validate image (optional)
├─ Process image for GitHub
└─ Include in issue body

FeedbackService
├─ Create issue with Octokit
└─ Format body with image

GitHub Issue
├─ Title with emoji
├─ Description
├─ ### Screenshot section
│  └─ ![screenshot](data:image/...)
└─ @Goroshik mention
```
