# Исправление: Сохранение подсказок в истории предложений

## Проблема

При сохранении сгенерированных предложений в истории подсказки (hints) удалялись, что делало невозможным понять, чем заполнять упражнения при восстановлении предложений из истории.

## Решение

### 1. Добавлено поле `hints` в схему БД

**Файл:** `prisma/schema.prisma`

Добавлено новое поле в модель `SentenceHistory`:

```prisma
model SentenceHistory {
  // ... другие поля
  hints       String[] @default([]) // подсказки для упражнения (например, формы глаголов)
  // ...
}
```

### 2. Обновлен репозиторий SentenceHistory

**Файл:** `src/repository/SentenceHistoryRepository.ts`

- Добавлен параметр `hints?: string[]` в методы `addHistory` и `addHistoryBatch`
- Подсказки теперь сохраняются в отдельном поле БД

### 3. Обновлен сервис генерации предложений

**Файл:** `src/services/generateTextService.ts`

Изменена логика обработки предложений:
- **Раньше:** Подсказки удалялись перед сохранением в БД
- **Теперь:** Подсказки извлекаются из предложений и сохраняются в отдельное поле `hints`

```typescript
// Извлекаем подсказки из формата: "Sentence (hint1, hint2)"
const hintMatch = sentence.match(/\s*\(([^)]+)\)\s*$/);
const hints: string[] = hintMatch
  ? hintMatch[1].split(/[,;]+/).map(h => h.trim()).filter(Boolean)
  : [];

// Удаляем подсказки из текста предложения
const sentenceWithoutHints = sentence.replace(/\s*\([^)]+\)\s*$/, '').trim();

// Сохраняем в БД
return {
  sentence: sentenceWithoutHints,
  hints, // сохраняем отдельно
  // ...
};
```

### 4. Обновлен сервис восстановления упражнений из истории

**Файл:** `src/services/trainingExercisesService.ts`

При восстановлении предложений из истории подсказки добавляются обратно:

```typescript
const data = sentences.map(s => {
  const hints = s.hints || [];
  if (hints.length > 0) {
    // Восстанавливаем формат с подсказками
    return `${s.sentence} (${hints.join(', ')})`;
  }
  return s.sentence;
});
```

## Результат

Теперь при восстановлении предложений из истории:
1. Подсказки сохраняются в БД при генерации новых предложений
2. Подсказки восстанавливаются в правильном формате при загрузке из истории
3. Пользователь видит подсказки в компоненте `TextWithInputs` как для новых, так и для исторических предложений

## Формат подсказок

Подсказки хранятся и отображаются в формате:

```
They **visited** many countries. (visit, visited)
```

Где:
- `**visited**` - правильный ответ (выделен жирным)
- `(visit, visited)` - подсказки (различные формы слова)

Компонент `TextWithInputs` автоматически парсит этот формат и отображает:
- Пропуск вместо жирного слова: `They _____ many countries.`
- Подсказку под полем ввода: `Подсказка: visit, visited`

## Требования для применения изменений

После применения этих изменений необходимо:

1. Запустить `prisma generate` для обновления Prisma Client ✅
2. Данные в существующей БД совместимы (поле `hints` имеет default `[]`)
3. Новые предложения будут сохраняться с подсказками
4. Старые предложения без подсказок будут работать (пустой массив)

## Миграция данных

Миграция данных не требуется - поле `hints` имеет значение по умолчанию `[]`, поэтому:
- Существующие записи автоматически получат пустой массив подсказок
- Новые записи будут сохраняться с подсказками (если они есть)
- Все работает без изменения существующих данных
