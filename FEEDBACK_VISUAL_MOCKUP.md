## Responsive Behavior

**Desktop (> 600px):**
- All header buttons visible in one row
- Modal: 600px width, centered
- Standard padding and spacing

**Tablet (600px - 960px):**
- Topic name hidden in header
- Modal: Full width with margins
- Compact button spacing

**Mobile (< 600px):**
- Only language name and hamburger menu
- Modal: Fullscreen
- All options in drawer menu
- Touch-optimized spacing

## User Flow Animation

```
1. User clicks 💬 button
   ↓
2. Modal slides in from center
   ↓
3. User selects type: 🐛 Баг or 💡 Фича
   ↓
4. User fills title and description
   ↓
5. User clicks "Отправить"
   ↓
6. Button shows loading spinner
   ↓
7. API creates GitHub issue
   ↓
8. Success message appears (green)
   ↓
9. Modal closes automatically
   ↓
10. User can continue using app
```

## States

### Default State
- Form is empty
- Type pre-selected to "Баг"
- Submit button enabled

### Loading State
- Submit button disabled
- Shows spinner icon
- Text: "Отправка..."
- Cancel button disabled

### Error State
- Red alert banner at top
- Form remains editable
- Submit button enabled
- User can retry

### Success State
- Green alert banner at top
- Modal closes
- Form resets for next use
