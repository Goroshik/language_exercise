# Чеклист для деплоя

## Предварительная подготовка

- [ ] **Выбрать платформу для деплоя** (см. рекомендации ниже)
- [ ] **Настроить MongoDB базу данных**
  - Рекомендуется: MongoDB Atlas (бесплатный tier доступен)
  - Важно: Требуется replica set для работы транзакций Prisma
- [ ] **Сгенерировать секретные ключи**
  ```bash
  # JWT_SECRET
  node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
  
  # TOKEN_SECRET (32 символа hex)
  node -e "console.log(require('crypto').randomBytes(16).toString('hex'))"
  ```

## Настройка переменных окружения

Скопируйте `.env.example` в `.env` и настройте следующие переменные:

### Обязательные:
- [ ] `DATABASE_URL` - Строка подключения к MongoDB
- [ ] `JWT_SECRET` - Секретный ключ для JWT токенов
- [ ] `TOKEN_SECRET` - Ключ для шифрования API токенов пользователей
- [ ] `JWT_COOKIE_NAME` - Имя cookie для JWT (по умолчанию: app_token)
- [ ] `JWT_EXPIRES_IN` - Время жизни JWT токена (по умолчанию: 7d)

### Опциональные:
- [ ] `REACT_APP_GOOGLE_TRANSLATE_API_KEY` - API ключ для Google Translate (резервный переводчик)

## Выбор платформы для деплоя

### Вариант 1: Vercel (Рекомендуется для быстрого старта) ⭐

**Преимущества:**
- Самая простая настройка
- Автоматический деплой при push
- Отличная поддержка Next.js
- Бесплатный tier
- Автоматический HTTPS

**Недостатки:**
- Нужна внешняя БД (используйте MongoDB Atlas)

**Шаги:**
1. Зарегистрируйтесь на [Vercel](https://vercel.com)
2. Импортируйте GitHub репозиторий
3. Добавьте переменные окружения
4. Нажмите Deploy

**Подходит для:**
- Хобби проекты
- MVP и прототипы
- Небольшие приложения
- Быстрый запуск

---

### Вариант 2: Railway

**Преимущества:**
- Встроенная MongoDB
- Простая настройка
- Автоматический HTTPS
- Удобное управление переменными

**Недостатки:**
- Ограниченный бесплатный tier

**Шаги:**
1. Зарегистрируйтесь на [Railway](https://railway.app)
2. Создайте проект из GitHub репозитория
3. Добавьте MongoDB сервис
4. Настройте переменные окружения
5. Деплой происходит автоматически

**Подходит для:**
- Full-stack приложения
- Проекты требующие БД
- Средний размер приложений

---

### Вариант 3: Render

**Преимущества:**
- Бесплатный tier
- Хорошая документация
- Поддержка Docker

**Недостатки:**
- Медленный cold start на бесплатном tier
- Нужна внешняя БД (используйте MongoDB Atlas)

**Шаги:**
1. Зарегистрируйтесь на [Render](https://render.com)
2. Создайте Web Service из GitHub
3. Добавьте переменные окружения
4. Настройте Build и Start команды
5. Деплой

**Подходит для:**
- Простые деплои
- Бесплатное хостинг для тестирования

---

### Вариант 4: DigitalOcean App Platform

**Преимущества:**
- Надежная инфраструктура
- Управляемые базы данных
- Хорошая производительность

**Недостатки:**
- Нет бесплатного tier
- Управляемый MongoDB дорогой (используйте Atlas)

**Шаги:**
1. Создайте аккаунт на [DigitalOcean](https://www.digitalocean.com)
2. Создайте App из GitHub
3. Добавьте переменные окружения
4. Настройте build команды
5. Деплой

**Подходит для:**
- Production приложения
- Средний и большой размер

---

### Вариант 5: Docker на VPS (Полный контроль)

**Преимущества:**
- Полный контроль
- Можно запускать на любом сервере
- Лучшее соотношение цена/качество для больших проектов

**Недостатки:**
- Требует настройки сервера
- Нужно управлять инфраструктурой

**Шаги:**
1. Арендуйте VPS (DigitalOcean, AWS, Hetzner и т.д.)
2. Установите Docker и Docker Compose
3. Клонируйте репозиторий
4. Настройте `.env` файл
5. Запустите: `docker-compose -f docker-compose.production.yml up -d`
6. Настройте Nginx и SSL (опционально)

**Подходит для:**
- Большие production проекты
- Когда нужен полный контроль
- Enterprise решения

## Сравнение платформ

| Платформа | Простота | Бесплатный tier | MongoDB | Лучше для |
|-----------|----------|-----------------|---------|-----------|
| **Vercel** | ⭐⭐⭐⭐⭐ | Да | Нет (Atlas) | Быстрый старт, MVP |
| **Railway** | ⭐⭐⭐⭐ | Ограниченный | Да | Full-stack, прототипы |
| **Render** | ⭐⭐⭐⭐ | Да | Нет (Atlas) | Простые проекты |
| **DigitalOcean** | ⭐⭐⭐ | Нет | Опционально | Production средний |
| **Docker/VPS** | ⭐⭐ | Нет | Ручная настройка | Production большой |

## Рекомендации

### Для разработки и тестирования:
**Vercel + MongoDB Atlas** (оба бесплатные tier)

### Для небольшого production:
**Vercel + MongoDB Atlas** (платные tier)

### Для среднего production:
**Railway** или **DigitalOcean App Platform**

### Для большого production/Enterprise:
**Docker на VPS** + управляемый MongoDB
