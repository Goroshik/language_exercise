# Инструкция по Деплою - Краткая Версия

## 🚀 Быстрый старт (5 минут)

Самый простой способ развернуть приложение - использовать **Vercel + MongoDB Atlas**.

### Пошаговая инструкция:

#### 1. Настройка MongoDB Atlas (2 минуты)

1. Регистрация на [MongoDB Atlas](https://www.mongodb.com/cloud/atlas) (бесплатно)
2. Создать кластер (Free tier M0)
3. Создать пользователя базы данных
4. Разрешить доступ со всех IP (Network Access → 0.0.0.0/0)
5. Скопировать строку подключения
   - Заменить `<password>` на пароль пользователя
   - Добавить `/exercises` перед `?`
   - Финальная строка: `mongodb+srv://user:pass@cluster0.xxxxx.mongodb.net/exercises?retryWrites=true&w=majority`

#### 2. Генерация секретных ключей (1 минута)

```bash
# JWT_SECRET
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"

# TOKEN_SECRET (должен быть ровно 32 символа)
node -e "console.log(require('crypto').randomBytes(16).toString('hex'))"
```

#### 3. Деплой на Vercel (2 минуты)

1. Зайти на [Vercel](https://vercel.com), войти через GitHub
2. Создать новый проект → импортировать репозиторий
3. Добавить переменные окружения:
   - `DATABASE_URL` - строка подключения из шага 1
   - `JWT_SECRET` - из шага 2
   - `TOKEN_SECRET` - из шага 2
   - `JWT_COOKIE_NAME` = `app_token`
   - `JWT_EXPIRES_IN` = `7d`
4. Нажать "Deploy"

**Готово!** Приложение доступно по адресу `https://your-app.vercel.app`

## 📋 Список платформ для деплоя

### Рекомендации по выбору:

| Ситуация              | Платформа                        | Почему                           |
| --------------------- | -------------------------------- | -------------------------------- |
| Быстро протестировать | **Vercel** + Atlas               | Самая простая настройка, 5 минут |
| Небольшой проект      | **Vercel** + Atlas               | Бесплатный tier, автодеплой      |
| Full-stack приложение | **Railway**                      | Встроенная MongoDB               |
| Production (малый)    | **Vercel** + Atlas (paid)        | Надежность + простота            |
| Production (средний)  | **DigitalOcean** или **Railway** | Больше контроля                  |
| Production (большой)  | **Docker на VPS**                | Полный контроль, лучшая цена     |

### Детальное сравнение:

#### 1. Vercel (⭐ Рекомендуется для начала)

**Плюсы:**

- ✅ Самая простая настройка
- ✅ Автоматический деплой при push
- ✅ Бесплатный tier
- ✅ Отличная поддержка Next.js
- ✅ Автоматический HTTPS

**Минусы:**

- ❌ Нужна внешняя БД (используйте Atlas)

**Подходит для:** MVP, хобби проекты, быстрый старт

---

#### 2. Railway

**Плюсы:**

- ✅ Встроенная MongoDB
- ✅ Простая настройка
- ✅ Удобное управление

**Минусы:**

- ❌ Ограниченный бесплатный tier

**Подходит для:** Full-stack приложения, средний размер

---

#### 3. Render

**Плюсы:**

- ✅ Бесплатный tier
- ✅ Хорошая документация

**Минусы:**

- ❌ Медленный cold start
- ❌ Нужна внешняя БД

**Подходит для:** Простые деплои, тестирование

---

#### 4. DigitalOcean App Platform

**Плюсы:**

- ✅ Надежная инфраструктура
- ✅ Хорошая производительность

**Минусы:**

- ❌ Нет бесплатного tier
- ❌ Управляемый MongoDB дорогой

**Подходит для:** Production приложения

---

#### 5. Docker на VPS (Полный контроль)

**Плюсы:**

- ✅ Полный контроль
- ✅ Лучшая цена для больших проектов
- ✅ Можно запустить на любом сервере

**Минусы:**

- ❌ Требует настройки сервера
- ❌ Нужно управлять инфраструктурой

**Подходит для:** Большие production проекты, enterprise

## ⚙️ Требования

### Обязательно:

- Node.js 20+
- MongoDB с replica set (Atlas делает это автоматически)
- Переменные окружения:
  - `DATABASE_URL` - подключение к MongoDB
  - `JWT_SECRET` - ключ для JWT токенов
  - `TOKEN_SECRET` - ключ для шифрования (32 hex символа)

### Опционально:

- API ключи для AI (пользователи могут добавить свои в настройках)
- Google Translate API ключ (резервный переводчик)

---

## 🔐 Безопасность

**Важно изменить в production:**

1. `JWT_SECRET` - сгенерировать сильный случайный ключ
2. `TOKEN_SECRET` - должен быть ровно 32 символа (используйте команду генерации)
3. `DATABASE_URL` - использовать безопасное подключение
4. Ограничить доступ к БД по IP (в MongoDB Atlas)

## ❓ Частые вопросы

### Какую платформу выбрать?

- **Для начала/тестирования:** Vercel (бесплатно, 5 минут)
- **Для production:** Vercel (paid) или Railway
- **Для больших проектов:** Docker на VPS

### Сколько это стоит?

- **Бесплатно:** Vercel free tier + MongoDB Atlas free tier (подходит для небольших проектов)
- **~$10-20/месяц:** Vercel Pro + Atlas Shared
- **~$50-100/месяц:** DigitalOcean или Railway для среднего проекта
- **$100+/месяц:** VPS для больших проектов

### Нужны ли API ключи?

API ключи для AI (Gemini, OpenAI, Claude) не обязательны при деплое - пользователи добавляют их сами через настройки приложения.

### Можно ли использовать другую БД?

Нет, приложение требует MongoDB с replica set для работы транзакций Prisma.
